## 🚀 HOW TO RUN (3 METHODS)

### Method 1: Automated (Easiest) ⭐ RECOMMENDED

**Windows:**
```

```

**Linux/Mac:**
```bash

```

### Method 2: Manual Setup

```bash

# Step 2: Initialize database
python database.py

# Step 3: Run application
```

```bash

```
